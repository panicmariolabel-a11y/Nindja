# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-11

### Added
- Initial release of Roulette Analyzer
- Educational statistics simulator interface
- Spin history tracking
- Probability analysis display
- House edge calculation and explanation
- Responsive web interface
- MIT License
- Contributing guidelines
- Bug report and feature request templates
- Comprehensive documentation
- Educational disclaimer and resources
- Support for 0-36 number input

### Changed
- Transformed from gambling system to educational tool
- Focus shifted to teaching probability and statistics
- Marketing language changed to emphasize learning

### Security
- Added disclaimer about gambling addiction resources
